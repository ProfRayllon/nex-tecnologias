# NEX Tecnologias

Site institucional da NEX Tecnologias: consultoria e plataformas SaaS para instituições de ensino, redes municipais e empresas (AVA Institucional e CRM Educacional).

🌐 https://nextecnologias.com.br

## Rodar localmente

Site estático (HTML, CSS e JS puros), sem build:

```bash
python -m http.server 8000
```

Abra http://localhost:8000

## Publicação

Hospedado no GitHub Pages (branch `main`, raiz). O domínio está definido no arquivo `CNAME`.
